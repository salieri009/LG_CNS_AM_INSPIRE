# 구현 기능 전체 목록 (영상 v2 기준표)

영상에 무엇을 담을지 빠짐없이 고르기 위한 기준표입니다. 2026-11-10 로컬 `feature/candidate-check` 기준(PR #6~#8 + 로컬 조각 1~5)입니다. 각 줄 끝의 [v1]은 1차 영상에 담긴 것, [—]는 빠진 것입니다.

## 0. 공통
- 화면 두 개: 정비사 화면 `/`, 공장·설계 화면 `/factory`. 상단 탭으로 오가며 상태가 유지됩니다. [v1]
- 차종 두 개: Tesla Model 3 (원본 FBX를 변환, 약 39만 꼭짓점), Tesla Model X (Sketchfab CC BY 4.0, STL 기반이라 원본 축으로 맞춤). [일부]
- 디자인: 검정 바탕, 흰 글자. 강조색은 목표 파랑·탈거 빨강·고전압 호박색만 씁니다. 글꼴은 IBM Plex Sans KR·Geist Mono를 번들에 넣어 오프라인에서도 같게 보입니다. [—]
- 접근성: 키보드 포커스 테두리, 화면 낭독기용 라벨, 움직임 줄이기 설정을 지킵니다. [—]
- 좁은 화면(900px 미만): 패널을 하나씩만 열고 불투명 배경으로 바꿉니다. 차를 고르면 오른쪽 패널로 넘어갑니다. [—]
- 3D 지연 로딩: 첫 화면 360kB가 먼저 뜨고, 3D는 뒤이어 불러옵니다. 3D가 실패하면 "매뉴얼로 계속 진행" 안내를 보여 줍니다. [—]
- 공개 배포판: 매뉴얼 그림 대신 원문 링크, 검색 노출 차단. [—]

## 1. 정비사 화면 · 왼쪽 패널 (정비사·차량)
- 정비사 카드: 이름, 정비소(비공개 표기), 경력, 자격 배지, 오늘 작업·기록 완료·진행 중 숫자. [—]
- 차량 선택: Model 3 세단 2017-2023, Model X SUV 2021-. 고른 차는 파란 테두리로 표시됩니다. [v1]
- VIN 직접 입력과 조회. 모르는 VIN은 "미등록 차량입니다" 오류를 보여 줍니다. [—]
- 예시 데이터·매뉴얼 출처·Model X 3D 출처 안내. [—]
- 패널은 상단 아이콘으로 열고 닫으며, 3D 영역이 그만큼 넓어집니다. 수리를 시작하면 자동으로 접힙니다. [일부]

## 2. 정비사 화면 · 상단 검색
- 돋보기를 누르면 검색창이 옆으로 펼쳐집니다. 차량을 고르기 전에는 잠깁니다. [—]
- 코드뿐 아니라 설명·증상 글자로 찾습니다(예: "헤드램프"). [—]
- 결과는 고른 차종 코드만 보여 주고, 검색 횟수를 함께 표시합니다. [—]
- 키보드 ↑↓로 고르고 Enter로 진단, Esc로 닫습니다(콤보박스). [—]

## 3. 정비사 화면 · 오른쪽 패널, 대기
- "방금 기록이 반영됐습니다" 결과 카드: 관측 25/48 → 26/49가 초록으로 한 번 튀고, 공장 화면으로 잇는 버튼이 있습니다. [v1]
- 접수 증상 칩: 자주 나오는 6개를 먼저 보이고 "증상 더 보기"로 펼칩니다. 고르면 맞는 고장코드가 위로 오고 나머지는 흐려집니다. [v1 일부]
- 고장코드 목록(차종별 4개): 코드, 설명, 증상 문장, 검색 횟수. [v1]
- 오늘 내 작업: 차종 표시, 시작 시각, "n/m단계에서 멈춤" 또는 "n분 걸림", 진행 중·완료 상태, 이어서·다시 보기 버튼. 다른 차종 작업을 이어하면 차량이 자동으로 바뀝니다. [v1 일부]

## 4. 오른쪽 패널, 원인 후보 (A②)
- 코드 카드: 함께 진단 중인 코드 전부 표시, "+ 코드 추가"(진단기에 더 뜬 코드), 코드 빼기(마지막 하나는 남음), 접수 증상 칩. [v1 일부]
- 후보는 공식 점검 순서대로 나옵니다. 순위, 이름, 관측 비율(n≥30일 때만 %), 분자/분모. [v1]
- 표본이 30건 미만이면 "표본 부족 (2/9건), 참고용"으로 표시합니다. [—]
- 배지: 공통 원인(여러 코드에 공통), 증상 일치, 고질 문제, 점검 완료·원인 아님, 원인 확정. [일부]
- 후보를 펼치면 관측 비율 막대, 정비사 기록 수, 다른 차종 비교("Model 3는 같은 코드에 7단계 · 표준 44분"), 수리 절차 요약(단계 수·예상 분·고전압 포함), 매뉴얼 대표 그림, 고전압 안내가 나옵니다. [일부]
- 점검 방법: 단계마다 정상 기준이 있고 체크합니다. 모두 정상이어야 "모두 정상 → 다음 후보"가 열리고(줄 긋기, 되돌리기 가능), "이상 있음 → 원인 확정"은 언제든 누를 수 있습니다. 교체 절차가 없으면 시연 범위 밖이라고 안내합니다. [v1 일부]
- 3D: 후보를 고를 때마다 카메라가 그 부품 쪽으로 날아가고 부품만 파랗게 보입니다. 차체 겉면 부품은 실제 면을 칠하고, 안쪽 부품은 종류별 모양으로 그립니다. [v1 일부]
- 진행 중인 작업이 있으면 "진행 중인 작업 이어서 (5/10단계)"로 바뀝니다. [v1]

## 5. 수리 (A③), 아래 매뉴얼 창
- 헤더: 대상 부품, n/m단계, 예상 분, 매뉴얼 원문 링크, 이전·다음, 접기 버튼. [v1]
- 카드: 매뉴얼 그림, 체결 방식·분·토크 태그, 설명, 지금 단계에는 정비사 팁(작성자·도움됐어요 수). 지금 카드로 자동 스크롤됩니다. [v1]
- 높이 조절: 위 손잡이를 끌면 300px부터 화면 절반까지, 키보드 ↑↓도 됩니다. 이 브라우저에 기억합니다. [v1]
- 접기·펼치기: 오른쪽 아래 원으로 빨려 들어가고 3D가 화면 끝까지 커집니다. 원에는 지금 단계가 보이고, 누르면 원에서 퍼져 나옵니다. [v1]
- 키보드 ←/→로 단계 이동. [v1]
- 단계 기록 줄: 이 단계 경과 시간(초 단위), 막혔어요(이유 4개), 팁 남기기(공개 여부). [v1]

## 6. 수리, 오른쪽 패널 진행 단계
- 진행 막대, 단계 목록(완료 체크, 지금 단계 빨강, 고전압 단계 호박색), 끝난 단계는 실제 걸린 분, 막힌 단계 표시. 단계를 누르면 그 단계로 갑니다. [일부]
- 원인 다시 고르기, 결과 기록(고전압 확인 전에는 잠김). [일부]

## 7. 수리, 3D
- 실제 차체 X-ray(비스듬한 면일수록 밝게) + 옅은 테두리 선. [v1]
- 부품 상태: 대기는 반투명, 지금 단계는 빨강으로 맥박, 목표는 파랑, 뗀 부품은 정해진 방향으로 빠지며 흐려짐. [일부]
- 차체 면 칠하기: 판 부품은 그 판이 향한 면만 칠합니다(도어 트림, 앞 범퍼, 에이프런, 헤드램프). [일부]
- 부품 모양: 배터리(단자), 커넥터(핀·잠금 탭), 볼트(육각 3개), 클립(고리), 모터·리졸버(원통·플랜지), 하네스(휘는 케이블), 수납함(위가 열린 통), 와이퍼(링크·모터), 레귤레이터(레일·케이블), 래치(몸체·고리), 문 윤곽대로 자른 판. [일부]
- 단계마다 카메라 위치가 정해져 있습니다. 사용자가 돌리면 따라가기를 멈추고, 다음 단계에서 다시 따라갑니다. [일부]
- 3D 위 라벨이 부품을 따라다닙니다("3단계 · 도어 글라스"). 3D 부품을 누르면 그 단계로 갑니다. [—]
- 실측 배치: Model X 팰컨 윙 도어(B필러~뒷바퀴 아치, 도어 속 공간 25cm), Model 3 후드 선·범퍼, 측정 영역을 벗어나면 테스트가 실패합니다. [—]

## 8. 고전압 안전 (P0A3F)
- 1단계 "리프트 고정·고전압 차단"에서 매뉴얼 위에 호박색 띠: 서비스 플러그 분리와 0V 확인 안내, 체크칸. [v1]
- 확인 전에는 다음 단계·결과 기록·키보드 이동이 모두 잠깁니다. [v1 일부]
- 확인 뒤 "고전압 차단·0V 확인 완료" 표시가 남고, 진행 단계에 "0V 확인"이 붙습니다. 카드·3D 라벨·진행 단계도 호박색입니다. [일부]

## 9. 결과 기록 (A④)
- 요약: 단계별로 잰 시간 합, 막힘 표시 단계와 이유, 남긴 팁 수. [—]
- 실제 원인(선택), 걸린 시간(잰 값 자동, 표준 시간을 미리 채우지 않음), 가장 오래 걸린 단계(막힘이 없으면 가장 오래 걸린 단계 자동), 모듈째 교체, 메모, 메모 공개. [일부]
- 장착 뒤 할 일(Model X: 새 배터리 학습, 서비스 모드 해제, 팰컨 윙 캘리브레이션)을 모두 체크해야 제출됩니다. [—]
- 제출하면 결과 카드, 작업 기록 완료, 원인 통계 n+1, 공장 지표 반영. [v1]

## 11. 공장·설계 화면
- 같은 틀: 3D 전체, 왼쪽 차종·요약(기록된 수리, 표준 초과 부품, 집중 탐지 수)·3D 색 읽는 법, 오른쪽 지표. [v1 일부]
- 보기 전환(정비 난이도 / 사양·생산 비교 / 고장 다발). [v1]
- B① 정비 난이도: 초과율 순, 평균 대 표준 막대(표준 눈금), 모듈째 교체, 가장 막힘, 설계 제안 문장. 3D에서 고른 부품은 파랑, 나머지는 초과 정도만큼 밝게. 3D 부품을 눌러도 고를 수 있습니다. [v1 일부]
- B② 사양·생산 비교: 차이가 큰 부품부터, 사양·시기·라인별 막대, "2018 하반기 Fremont 생산분이 54분 더" 문장. [v1 일부]
- B③ 고장 다발: 코드별 실제 원인 분포, 최다 원인 비율, 집중 탐지(어느 생산분에 몰렸는지). 정비사 기록이 바로 반영됩니다. 3D는 원인 비율만큼 밝게. [v1]
- 차종 전환 시 3D·지표·요약이 모두 바뀝니다. [—]
