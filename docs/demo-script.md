# 시연 대본 (발표 12번 PROTOTYPE DEMO, 약 2분)

README 데모 루프(A① → A② → A③ → A④ → B①)를 그대로 따라가는 클릭 순서입니다. 숫자는 목업 첫 상태 기준이라, 시연 직전에 새로고침해서 처음 상태로 맞춥니다. 실행 방법은 [로컬 실행 안내](local-preview.md)를 따릅니다.

## 준비
- 브라우저 창은 가로 1440px 이상으로 둡니다. 좁으면 패널이 하나씩만 열립니다.
- 주소창에서 `localhost:5180`을 새로고침합니다. 목업 데이터는 메모리에만 있어서 새로고침하면 처음으로 돌아갑니다.
- 3D가 뜨는 데 몇 초 걸립니다. 첫 화면이 먼저 나오고 3D는 뒤이어 들어옵니다.

## 흐름

| # | 하는 것 | 화면에서 보일 것 | 말할 것 |
|---|---|---|---|
| 1 | 왼쪽 "Tesla Model 3" 클릭 | 오른쪽에 사양 Long Range RWD · 2018-06 | A① VIN 하나로 사양·생산 시기가 잡힙니다 |
| 2 | 접수 증상 "문이 안 열림" 클릭 | B1A24가 맨 위로, 나머지 코드는 흐려짐 | 코드를 몰라도 증상으로 시작할 수 있습니다 |
| 3 | B1A24 클릭 | 1순위 리어 도어 래치 52% (관측 25/48건), 3D는 래치 위치로 이동 | A② 공식 점검 순서 그대로, 같은 사양에서 실제로 확인된 비율을 n과 함께 봅니다 |
| 4 | (선택) "+ 코드 추가"에서 B0F71 | 12V 배터리 전압 저하가 "공통 원인 B1A24 + B0F71"로 맨 위 | 진단기에 코드가 여러 개 뜨면 공통 원인부터 봅니다. 확인 뒤 "빼기"로 B0F71을 뺍니다 |
| 5 | 1순위 점검 단계 두 개 체크 → "이상 있음 → 원인 확정" | 파란 "점검 결과 원인 확정" 표시 | 이상이 없으면 "모두 정상 → 다음 후보"로 넘어갑니다 |
| 6 | "이 원인으로 수리 진행 →" | 아래 매뉴얼 7단계, 3D에서 실제 도어 트림 면이 빨갛게 | A③ 무엇을 먼저 떼야 하는지 작업 전에 보입니다 |
| 7 | 키보드 → 로 단계 넘기기, 매뉴얼 접기 버튼 | 단계마다 부품이 빠지고, 접으면 3D가 크게 | 실제 매뉴얼 그림과 토크·공구가 같이 나옵니다 |
| 8 | (선택) "막혔어요" → "부품 고착" | 진행 단계에 "막힘" 표시 | 막힌 곳은 단계마다 남고 공장으로 갑니다 |
| 9 | 마지막 단계에서 "결과 기록 →" → 실제 원인 래치, 시간 확인 → "기록하고 마치기" | 결과 카드 "관측 25/48건 · 52% → 26/49건 · 53%" | A④ 1분 기록이 다음 정비사의 비율을 바꿉니다 |
| 10 | 결과 카드의 "공장 화면에서 보기 →" | 3D 위에 정비하기 어려운 부품이 밝기로, 헤드램프 +78% | B① 공장은 조립 효율만 보던 설계를 정비 난이도로 다시 봅니다 |
| 11 | 오른쪽 위 "고장 다발" → B1A24 | 원인 분포 막대, "집중 탐지 · 2018 상반기 LR RWD" | 방금 기록이 원인 분포에 바로 더해졌습니다 |

## 시간이 남으면 (차종별 차이)

| 하는 것 | 보일 것 | 말할 것 |
|---|---|---|
| 상단 "정비 진단" → 왼쪽 "Tesla Model X" → B1A24 | "Model 3는 같은 코드에 7단계 · 표준 44분", Model X는 10단계 | 같은 고장코드라도 VIN마다 절차가 다릅니다 |
| 수리 진행 → 래치 단계 | 팰컨 윙 도어 실측 윤곽 안의 부품 | 실제 차체를 재서 부품 위치를 잡았습니다 |
| Model 3 P0A3F 수리 진행 | 1단계 호박색 고전압 띠, 체크 전 다음·결과 기록 잠김 | 고전압 단계는 확인 전에는 넘어갈 수 없습니다 |

## 문제가 생기면
- 3D가 안 뜨면 "3D를 불러오지 못했습니다" 안내가 나오고, 매뉴얼 그림과 단계 안내로 그대로 진행할 수 있습니다.
- 숫자가 대본과 다르면 이미 한 번 기록한 상태입니다. 새로고침하면 처음으로 돌아갑니다.
- 모든 건수·시간·팁·고장코드 번호는 예시 데이터라고 먼저 말해 둡니다.
