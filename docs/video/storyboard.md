# 시연 영상 스토리보드

## 방향
- 모티브: 애플 제품 필름(검정 화면, 큰 한글 타이포가 한 줄씩 떠오름, 말없이 기능으로 설득)과 테슬라 화면의 절제. 장식은 앱 디자인 토큰(검정·흰색, 목표 파랑, 탈거 빨강, 고전압 호박색, IBM Plex Sans KR·Geist Mono) 안에서만 씁니다.
- 음성(TTS) 없음. 화면 아래 자막 두 줄(작은 단계 라벨 + 한 문장)과 클릭 지점의 얇은 원으로 뜻을 전합니다. 마우스 포인터는 보이지 않습니다.
- 박자: 120 BPM 기준(한 마디 2초). 장면 전환과 자막 교체는 마디 시작에 맞춥니다. 음악은 경쾌한 일렉트로닉, 보컬 없음, 118~124 BPM을 받으면 박자에 다시 맞춥니다.
- 길이: 약 3분. 화면은 1920×1080, 30fps, 실제 앱을 스크립트로 조작해 한 번에 녹화합니다 (`frontend/film`).

## 지키는 것
- 모든 수치는 예시 데이터라는 점을 끝 화면에 작게 표기합니다.
- 실제 화면만 씁니다. 화면에 없는 기능을 자막으로 약속하지 않습니다.
- 자막은 한 번에 한 문장, 읽을 시간을 최소 2초(한 마디) 줍니다.
