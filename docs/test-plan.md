# 테스트케이스 기획

> [기획서 13장](planning.md#13-테스트케이스-기획)과 같은 내용. 장 번호(6장, 14장 등)는 [기획서](planning.md) 기준이고, 배포 검증은 [EKS 배포 기획](deployment-eks.md)과 이어짐. 상태 열은 2026-11-09 기준.

시연 전에 반드시 통과시킬 테스트는 P0 24개임 (시연 경로, 고전압 잠금, 권한, 익명화, 통계 경계값, 배포 검증). P1·P2는 남는 시간만큼 진행하고, 상태 열은 팀이 직접 바꿈. 도구와 기준 숫자는 제안이라 팀 확정이 필요함.
