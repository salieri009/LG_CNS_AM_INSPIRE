# 시연 영상 v2 계획 (토큰 리셋 뒤 바로 실행)

v1(2분 11초)은 흐름 확인용 초안이었습니다. 리뷰에서 나온 문제는 세 가지입니다.
1. 화질이 선명하지 않다.
2. 구현한 것이 다 담기지 않았다. 기능표([feature-inventory](feature-inventory.md))에서 [—]인 항목이 절반이 넘습니다.
3. 짧다.

## 1. 화질이 흐린 이유와 해결

| 원인 (v1 녹화 방식) | 결과 | v2 해결 |
|---|---|---|
| 화면 배율 1배(1920×1080 그대로)로 그림 | 글자와 X-ray 선이 1픽셀이라 계단이 생기고 뭉개짐 | 2배 이상으로 그려 4K(3840×2160)로 받고 줄여서 씀(슈퍼샘플링) |
| 프레임을 JPEG 92%로 받음 → H.264로 다시 압축 | 얇은 선과 작은 글자에 이중 압축 손상 | PNG(무손실)로 받고 마지막에 한 번만 압축 (4K CRF 14, 1080p CRF 16, tune film) |
| 앱이 1440px 화면 기준이라 1920에선 글자가 작음 | 영상에서 글자가 더 작고 흐려 보임 | 논리 화면 1600×900에 배율 2.4로 그림 → 4K. 같은 화면이 영상에서 20% 크게 보임 |
| 클로즈업이 없음 | 패널 글자·3D 부품을 읽을 수 없음 | 4K 원본에서 잘라 확대(1.5~2배 펀치인)해도 1080p 선명. 클릭한 요소 위치를 녹화 중에 기록해 확대 위치를 자동으로 정함 |
| 화면 변화가 있을 때만 프레임이 와서 3D가 무거우면 끊김 | 카메라 이동이 덜컥거림 | 장면 시작 전 3D를 미리 띄우고, 녹화 전 품질 시험으로 4K PNG에서 초당 프레임을 재서 28 미만이면 배율을 2로 낮춤 |
| 공유용 720p(CRF 24)로 보내 드림 | 미리보기가 원본보다 훨씬 흐림 | 리뷰용도 1080p로 보냄 |

## 3. 제작 방식 (v1 도구를 키워서 씀)
- 장면 단위 녹화: `film/shots/<번호>-<이름>.mjs`마다 새 페이지에서 상태를 맞추고(`window.__repairStore`) 녹화합니다. 한 장면이 실패해도 그 장면만 다시 찍습니다.
  - 러너: `node film/run.mjs [장면…]`
  - 결과: `film/out/shots/<장면>/frames`, `events.json`(클릭 위치·시각)
- 편집: `film/timeline.json`(장면 순서, 자를 구간, 자막, 펀치인, 장 타이틀, 전환)을 `film/edit.mjs`가 ffmpeg로 합칩니다.
  - 전환: 0.5초 디졸브(xfade), 장 타이틀은 검정 카드
  - 펀치인: events.json의 클릭 위치로 crop을 부드럽게 확대·축소
  - 분할 화면: 두 장면을 hstack으로 나란히
- 자막: v1처럼 페이지 위 레이어로 4K에서 그립니다(선명).
  - 장 번호와 제목은 장 타이틀 카드에 넣습니다.
  - 한 문장은 최소 2초, 장면당 1~2문장입니다.
- 음악: 120 BPM 기준 마디에 맞춰 자릅니다.
  - 전체판(약 9분)은 곡 하나가 짧으면 두 곡을 장 경계에서 이어 붙입니다.
  - 곡 길이·박자는 ffprobe로 재고, 시작 위치를 맞춥니다.
- 결과물: `cardoc-full-4k.mp4`, `cardoc-full-1080p.mp4`, `cardoc-short-1080p.mp4`, 리뷰용 장별 연락표(contact sheet).

## 4. 아침 실행 순서 (예상 시간)
1. 품질 시험 (20분): 1600×900 배율 2.4/2.0, PNG/JPEG100으로 10초씩 녹화해 초당 프레임과 선명도를 비교하고 설정을 고릅니다.
2. 도구 정리 (40분): record.mjs를 장면 러너, 사건 기록, 편집 스크립트로 나눕니다.
3. 장면 스크립트 (1시간 30분): 위 구성의 장면 약 35개를 씁니다. 한 장씩 녹화하고 연락표로 확인합니다.
4. 편집 (40분): 타임라인, 펀치인, 분할 화면, 장 타이틀.
5. 음악 (20분): 받은 곡으로 박자 맞춤, 음량 -14 LUFS, 짧은판 잘라내기.
6. 검수 (20분): 1080p 전체 보기, 오탈자·자막 타이밍·끊김 확인, 고칠 장면만 다시 찍기.

## 5. 준서님이 정해 주실 것
- 음악: 전체판용으로 4분 이상 곡 두 개, 또는 9분 이상 곡 하나. 경쾌한 일렉트로닉, 보컬 없음, 118~124 BPM. 짧은판은 그중 하나를 씁니다.
- 배포 주소: 아웃트로 QR에 넣습니다. 배포 전이면 자리만 비워 둡니다.
- Model 3 3D 라이선스: 공개 영상·사이트에 써도 되는지.
- 길이: 전체판 약 9분, 짧은판 약 2분 30초로 가도 될지. 더 짧거나 길게 원하시면 장 단위로 조정합니다.
